# Desktop workshop / R01 reference pass

Applied to OpenWorldRecovery, using existing URP and native nature assets.

- Before / After: identical 1280×720 Editor views; authored colour grading, no photographic depth of field or extra vehicle fill. Not gameplay FPS evidence.
- Authoring.json: decoration counts and authoring preservation checks.
- Checks.json: shader/reference checks and desktop/Switch layer policy.
- Lighting.json: direct invocation of weather lighting for clear/rain/night on both profiles; original lights restored afterwards.

No builds were produced. No target-PC frame timings were measured. Native resolution retained; PC Quality profile receives the rendering upgrade (Performance remains an optional lower-cost setting).
