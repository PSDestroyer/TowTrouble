# Wheel surface debris — 2026-11-07

Implemented on the existing RecoveryWheelMud component, with no new runtime manager. Coarse mesh grains and fine billboard powder vary for mud, sand, snow, dirt and grass; hard stone only emits sparse chips during significant slip, and wood emits none. The actual wheel contact and painted/marked surface determine the kind. Contact normal, steered axle, measured rolling direction, speed and actual wheelspin determine the throw. Braking input cannot invert a rolling plume. Existing tire coating remains intact.

RecoveryWheelMudDebris caches serialized emitters/resolver and reuses the existing four coarse particle systems. Four powder systems added per vehicle; bounds are28 coarse+14 fine per wheel,168 per car /504 across the three authored vehicles. Shared two materials and one low-poly irregular grain mesh; no particle collisions, per-frame object creation, material instances or VFX network messages. The legacy chassis dust emission is suppressed while the surface system owns wheel feedback. Pause/disable/reset/geometry swap clean up correctly.
