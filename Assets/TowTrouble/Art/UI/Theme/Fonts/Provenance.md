# UI typography

Tow Display: static weight 700 instance of Fredoka, width default. Tow Text: static weight 600 instance of Nunito Sans, other axes at defaults. Derived font family names renamed for the project. Source files retrieved 2026-10-31 from the official google/fonts repository. Original copyrights and SIL OFL 1.1 texts are included.

https://github.com/google/fonts/tree/main/ofl/fredoka
https://github.com/google/fonts/tree/main/ofl/nunitosans

Tow Display adds Romanian A-breve and S/T comma-below composites using the original Fredoka letter, breve and comma outlines. The derived font retains the original copyright and OFL license.
